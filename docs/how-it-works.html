How deskwork works

1What you hand it
The task, in full
File the Q3 2025 Quality Improvement report for the Pharmacy department. Use report ID QI-2025-014.

The attestation questions ask for specific regulatory facts. Look each one up in the corpus before answering, and give the citation the corpus gives you.
The corpus
Three US federal publications on HIPAA Administrative Simplification — public domain, shipped with the repo.
cms-0055-f-ncpdp-d0-final-rule-2020.pdf
cms-hipaa-d0-information-bulletin-2020.pdf
cms-hipaa-statutes-timeline-2021.pdf
173 chunks, embedded locally. No embeddings API.
Where this demo is shaped
The four questions were written from the corpus, so each one is answerable. That fixes what is findable — not when the agent learns what it is being asked, and not whether it looks.
That is everything. It has never seen the form, and the questions it will be asked are nowhere in this prompt.

What is not enforced
The system prompt forbids answering a regulatory question from memory. The model obeying it is cooperation, not a guarantee — nothing in the loop can stop it inventing a rule number.

Fabrication is not prevented here. It is caught below.
